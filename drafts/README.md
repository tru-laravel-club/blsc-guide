| --- | --- |

| `membership-info`, `parties-info`, `quarks-info` | `category-descriptions`, `membership-plans` |
| `party-invitations` | `downloads` |
| `science-articles`, `articles-admin` | `pages-posts` |
| `saturday-programs-admin`, `weekly-themes-admin` | `session-details` |
| `quarks-application` | `applications` |

Delete a draft when the new feature that replaces it has steps.
